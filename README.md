# OOPS

## Overview

OOPS is a 2D side-scrolling underwater adventure game developed with Unity. Players control a bubble character and navigate handcrafted stages, using bubble-like movement to overcome obstacles and complete level challenges.

## Gameplay and Systems

- Physics-based bubble movement and simulation.
- Interactive mechanisms that shape traversal and level challenges.
- A level-logic system connecting obstacles, interactions, and stage progression.
- 2D underwater environments and art supporting the game's atmosphere.
